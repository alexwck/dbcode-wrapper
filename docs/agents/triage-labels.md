# Triage labels

| Canonical role | Local label | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Needs maintainer review |
| `needs-info` | `needs-info` | Waiting for more information |
| `ready-for-agent` | `ready-for-agent` | Ready for an agent to handle |
| `ready-for-human` | `ready-for-human` | Requires human work |
| `wontfix` | `wontfix` | Will not be actioned |

Use the local label whenever an engineering skill refers to its corresponding canonical role.
