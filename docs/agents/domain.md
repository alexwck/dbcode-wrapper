# Domain docs

This repository uses a single domain context.

Before exploring, read these files when they exist:

- `CONTEXT.md`
- Relevant decisions under `docs/adr/`

Do not create them merely because they are absent. The domain-modeling workflow creates them when terminology or a lasting architectural decision is actually resolved.

Use terminology defined in `CONTEXT.md`. If proposed work conflicts with an existing architectural decision, identify the conflict instead of silently overriding it.
